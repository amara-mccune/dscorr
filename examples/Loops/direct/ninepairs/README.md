Mode tables and loop grids used by `../direct_fermi.py` and `../direct_fermi_adapt.py`.

`full.py`, `modes.py`, and `softmoment.py` are copied unchanged from `loops_numcheck_code.zip` (folder `ninepairs/`),
the numerical checks of the loops paper. They need numpy and python-flint. Mode tables are cached in `cache/` here
(about 1 MB, not tracked). To use another copy of the helpers, set the environment variable `NINEPAIRS` to its folder.
